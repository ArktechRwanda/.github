# ArkTech

ArkTech builds AI, data, geospatial, and enterprise software for governments, NGOs, and businesses.

Our work focuses on practical systems for field operations, land administration, organizational data, private AI, satellite intelligence, and web GIS.

## Products in development

- **ArkField** — offline-first geospatial field operations
- **ArkLand** — land administration and parcel records
- **ArkData** — governed data integration and analytics
- **ArkAI** — private organizational AI
- **ArkVision** — satellite and aerial intelligence
- **ArkMaps** — enterprise web GIS
